# Legacy Python scripts

Digantikan penuh oleh `spse.py` di root repo. Jangan dijalankan atau diubah;
disimpan hanya sebagai referensi historis. Untuk kebutuhan apapun (instansi,
tahun, kategori, CSV, Excel) gunakan `spse.py`.

| File | Catatan |
|---|---|
| `spse_pipeline.py` | Pipeline versi sebelum `spse.py`: CLI saja, 3 kategori, tanpa GUI dan tanpa Excel. |
| `scrape_all.py` | Hardcoded Kemkes 2025: JSON + HTML saja, tanpa CSV. |
| `scrape_lelang_jakarta.py` | Hardcoded instansi jakarta, satu kategori. |
